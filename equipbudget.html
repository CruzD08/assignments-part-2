My Work Station Budget

Item Description Cost Why?
MacBook Air
Model: MacBook Air Size: 13-inch Chip: Apple M3 Memory (RAM): 8 GB Storage: 256 GB SSD Graphics: Integrated Apple GPU (comes with the M3 chip) Display: 13.6-inch Retina Display (2560 × 1664) OS: macOS Sequoia $1,400 I use a MacBook because it is lightweight and easy to carry to class and different locations. It has been very useful for my school assignments, and it allows me to easily transfer information from my iPhone to my Mac, which helps me stay organized and work more efficiently.
HP Laptop
Model: HP 15-dy5023st CPU: Intel Core i3 (12th Gen) Memory (RAM): 8 GB Storage: 256 GB SSD Graphics: Integrated Intel UHD Graphics Display: 15.6” Full HD Operating System: Windows 11 $350 I purchased this HP laptop to install keyboard-related software and to use Windows-based programs required for my DAT classes, such as Microcomputer Applications and Excel. It allows me to work with programs that are not always compatible with macOS.
Adobe
Applications: Dreamweaver, Photoshop, Illustrator, etc Platform: macOS and Windows Use: Web design, graphic design, and creative projects $0.00 (Free with school access) Thanks to my school, I am able to use Adobe Creative Cloud for free. I started using it for my BIS 13 class, specifically for Dreamweaver. Adobe offers many tools that are useful for web design, editing, and creative projects, which makes it helpful for both schoolwork and future professional use.
External Monitor Dell 24 Plus Monitor - S2425HSM
Display Size: 23.8” Resolution: Full HD (1920 × 1080) Refresh Rate: 144 Hz Panel Type: IPS Connection: HDMI Features: Anti-glare, eye comfort technology $129.99 An external monitor helps me work more efficiently by giving me more screen space. It is especially useful for Excel, research, and completing school assignments while keeping multiple windows open at the same time.
HP DeskJet 2755e Printer
Type: Inkjet Printer Functions: Print, Scan, Copy Connectivity: Wireless $60 This printer is useful for printing school assignments, documents, and forms at home. It also allows me to scan and copy documents when needed, which is helpful for school and personal use.
External Hard Drive
Brand: Seagate Model: Backup Plus Storage Capacity: 5 TB Drive Type: External HDD Connection: USB 3.0 Compatibility: Mac and PC $119 This external hard drive provides a large amount of storage for backing up important files and school projects. It helps keep my data safe and allows me to store documents, assignments, and backups outside of my main computer.
Canon GX7
Lens: 4.2x optical zoom (24–100mm equivalent) Aperture: f/1.8–2.8 Stabilization: Image stabilization Screen: 3.0” touchscreen Connectivity: Wi-Fi and Bluetooth Charging: USB charging $1,500 I chose this camera for my travels because it allows me to capture high-quality photos and videos. It is useful for documenting trips, creating content, and preserving memories, while also being easy to transfer files to my computer for storage and editing.
